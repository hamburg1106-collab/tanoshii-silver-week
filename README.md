# 楽しいシルバーウイーク

2026/9/22の東京ディズニーランドで、当日の動きを決めるための家族用アプリ。スマホ専用。

公開先： https://hamburg1106-collab.github.io/tanoshii-silver-week/

## 何をするアプリか

計画どおりに進むなら要らない。**ズレたときに立て直すための道具**。

最適化するのは待ち時間ではなく、**歩行と立ち時間を抑えつつ90分ごとに着席させること**。高齢の家族2人と2歳児が一緒に動くため。

### 提案の仕組み

ルールベース。LLMは使っていない。理由は3つ。

- 提案の根拠を画面に出せる（当日それを読み上げて家族を動かせる）
- 電波が切れても動く（舞浜は連休に通信が詰まる）
- APIキーを家族に配らずに済む

### 柊モード

ベビーカーはアトラクションに持ち込めないため、**寝ている間はライドとグリーティングが全滅する**。減点ではなくモード切替として実装している。

| 状態 | 除外 | 加点 |
| --- | --- | --- |
| 元気 | — | グリーティング・体験型。待ち25分超は強く減点 |
| 眠い | 大音量・暗いもの | 寝落ちしやすい乗り物 |
| 寝ている | ライド・グリーティング全部 | 移動・買い物・食事・パレード |
| 起きた直後 | 待ちの長いもの | 食事・休憩 |

昼寝は「ロス」ではなく「歩く時間」として扱う。

### 入力設計

能動的に押すのは「ここに行く」だけ。これ1回で現在地と最後に座った時刻が同時に決まる。
眠気はアプリの方から聞いてくるので、押し忘れが構造的に起きない。

## 開発

```
npm install
npm run dev -- --host   # スマホ実機から見るとき
npm run build
npm run lint
node scripts/make-icons.mjs
```

`main` に push すると GitHub Actions が GitHub Pages へデプロイする。

## データ提供元

待ち時間は [Queue-Times.com](https://queue-times.com/en-US) から取得している。

**画面への「Powered by Queue-Times.com」表示は利用条件。消さないこと。**

東京ディズニーリゾート公式サイトを直接スクレイピングしてはいけない（規約で明示的に禁止されている）。
キャラクター画像・ロゴ・公式フォントも使わない。
